# ONG Solidária

Projeto front-end desenvolvido como experiência prática acadêmica, com foco na criação de uma plataforma web para uma organização do terceiro setor.

## Objetivo

O projeto tem como objetivo apresentar a ONG, divulgar projetos sociais, permitir o cadastro de voluntários e aplicar boas práticas de desenvolvimento front-end, acessibilidade, responsividade e organização de código.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- LocalStorage
- ES Modules
- WebP
- Git/GitFlow
